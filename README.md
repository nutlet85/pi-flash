![pi-flash 封面](docs/images/pf-cover.png)

**pi-flash** 是 Windows 上的 Pi coding-agent 工作台：原生 Rust + GPUI，Agent 真相在 Pi，壳负责会话 UI。不是通用 IDE。

产品边界见 [docs/PRODUCT.md](docs/PRODUCT.md)，决策见 [docs/INTENT.md](docs/INTENT.md)，架构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

需要 Node.js ≥ 22.19
> 平台范围：**正式发版仅 Windows x64**。macOS 是 best-effort 源码构建，不进正式 Release（见 INTENT D12）。
